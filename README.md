# Trello 甘特圖

把 Trello 看板上的卡片畫成甘特圖。可依成員與卡片狀態篩選,直接在圖上拖曳調整日期、管理成員與留言,並匯出 Excel 與 PDF。

純前端網頁,不需要自己架伺服器。可以直接用瀏覽器開啟,也可以掛成 Trello Power-Up,在看板上按一個按鈕開啟。

## 功能

### 甘特圖顯示
- **選擇看板**:列出你有權限且未封存的看板,可多選。
- **預設從今天開始**:開啟時畫面最左邊(卡片欄右側)就是今天,往左捲動可看過去的日期。
- **回到今天**:按工具列的「今天」按鈕,或圖表頂端橘色的「今天」標籤,即可回到預設位置。
- **時間刻度**:可切換「日 / 月 / 年」,放大看每天的細節,或縮小看整體進度。
- **成員一起顯示**:一張卡片有多位成員時,全部會以標籤並列顯示在卡片名稱旁。
- **列表(list)名稱**:每個看板可分組顯示卡片所屬的列表。列表標題帶有看板顏色的底色、左側色條與「列表」標籤,卡片則縮排在下方,一眼就能分辨。在圖中看板那一列勾選或取消「顯示列表」,即可切換。關閉時,每張卡片旁會改以小標籤標示所屬列表。
- **卡片名稱樣式一致**:所有卡片名稱使用相同字型與顏色,不再因為有無日期而變成斜體或灰色。
- **狀態標示**:已完成的卡片顏色變淡,未完成且已逾期的卡片加紅框,橘色線標出今天,週末有淡灰底色(日刻度)。
- **收合 / 展開列表**:點列表標題即可收合或展開該列表的卡片,工具列另有「收合全部列表」與「展開全部列表」。收合的列表仍可作為拖曳卡片的目標。
- **列表卡片數**:列表標題右側的圓形標籤顯示該列表的卡片數。使用成員篩選或隱藏無日期、無成員卡片時,會顯示成「顯示中 / 列表總數」,例如 `3 / 11`。
- **深色 / 淺色模式**:右上角「主題」可選「跟隨系統」「淺色模式」「深色模式」,選擇會記在瀏覽器中。整個頁面、甘特圖、列表標題與卡片視窗的配色都會一併切換。

### 篩選
- **顯示成員**:只看某位成員,或只看「未指派」的卡片。選擇某位成員時,卡片成員包含他、或有自訂區間指定給他的卡片都會顯示;指定給其他成員的區間則會隱藏,沒有指定成員的區間照常顯示。
- **顯示無日期卡片**:勾選時,沒有任何日期的卡片也會列出(沒有色條)。
- **顯示無成員卡片**:勾選時,沒有成員的卡片也會列出。

### 直接在圖上編輯
- **調整日期**:拖曳色條左邊緣改開始日期、右邊緣改結束日期,拖曳中間可整段移動。放開滑鼠後自動寫回 Trello,拖曳時會顯示即時日期。
- **新增日期**:在**沒有完整開始與結束日期**的卡片空白處拖曳,可設定該卡片的原生日期。已有完整日期的卡片,在空白處拖曳會改為新增一段「自訂時間區間」(見下方「多段時間區間」)。
- **移動與排序卡片**:開啟「顯示列表」時,拖曳卡片左側的 ⋮⋮,可放到其他列表,或在同一列表內調整順序。拖曳時會出現橘色線標示放開後的位置,放開後自動寫回 Trello。
- **卡片視窗**:點卡片名稱(或點一下色條),可以:
  - 用日期欄位修改或清除開始、結束日期
  - 新增或移除卡片成員(只能選該看板的成員)
  - 查看卡片描述(唯讀,以純文字顯示)
  - 查看所有留言(含作者與時間),新增留言,並編輯自己寫的留言

### 匯出
- **Excel(.xlsx)**:每一段時間區間一列,欄位為看板、列表、卡片、區間類型(原生 / 自訂)、區間名稱、區間成員、開始日期、結束日期、天數、已完成、成員、連結。有多段自訂區間的卡片會有多列。「卡片」與「連結」兩欄都已設定超連結,點一下即可在 Trello 開啟該卡片。
- **PDF**:按「匯出 PDF」後可選擇**時間區間**(預設今天起往後一個月)、紙張(A4 / A3)、方向(橫 / 直)、內容大小(大 / 標準 / 小),並可選擇是否包含無日期卡片。內容多時自動分成多頁,每頁都會重複卡片欄與日期標題,文字大小維持清楚易讀,頁尾標示頁碼與該頁的日期範圍。
- 兩者都只輸出目前篩選後看到的卡片。

## 多段時間區間

一張卡片原生只有一組開始與結束日期。本工具讓你另外建立**多段時間區間**,每一段以一則**留言**儲存在該卡片上,**一段區間 = 一則留言**。

### 留言格式
固定格式為:

```
#@user@!title!${start:YYYYMMDD}:{end:YYYYMMDD}$#
```

- `@user@` 是區間負責的成員(Trello 使用者名稱),**可省略**。沒有指定成員時,留言中就不會出現這一段。
- `title` 是區間的名稱,會顯示在甘特圖中該區間那一列,預設為 `----`。
- 日期為 8 位數字的 `YYYYMMDD`。
- 實際寫入 Trello 的留言例如:
  - 沒有成員:`#!----!$20261012:20261020$#`
  - 指定成員:`#@amy@!二次測試!$20261101:20261105$#`
- 名稱中的 `!` 會自動改成全形的 `！`,避免與格式的分隔符號衝突。
- 留言中,格式以外的文字會當作備註,顯示在區間名稱後方。
- 為了相容舊版,舊格式 `#$YYYYMMDD:YYYYMMDD$#` 仍可被讀取(沒有名稱與成員),在這裡調整後,會改寫成新格式。

### 操作
- **建立**:只有已設定**原生開始與結束日期**的卡片才能建立。在該卡片的空白處拖曳(名稱為預設的 `----`,不指定成員),或在卡片視窗的「多段時間區間」選擇成員(可不選)、填入名稱與日期後按「新增時間區間」,就會新增一則留言。
- **顯示**:每一段區間顯示在卡片下方的獨立一列,以斜線色條呈現,與原生的實心色條區分。列左側顯示區間名稱、日期(MM-DD,滑鼠停留可看完整日期)與區間成員。
- **指定成員**:在該列的成員下拉選單(或卡片視窗的區間清單)選擇成員,會改寫對應的留言;選「不指定成員」則會拿掉 `@user@`。下拉選單列出該看板的成員。
- **改名**:點該列的區間名稱(或在卡片視窗按「改名」),輸入新名稱,會更新對應的留言。
- **調整**:拖曳斜線色條的左右邊緣或中間,放開後會更新對應的留言。
- **刪除**:按該列左側的 ✕(或在卡片視窗按「刪除」),會刪除對應的留言,刪除前會再確認。
- 匯出 Excel 時,每一段區間各佔一列(含區間成員);匯出 PDF 時,與所選時間區間重疊的區間也會一併列出。

### 注意
- 區間是留言,**看板上的其他成員也看得到**這些留言。
- **指定成員時,留言內含 `@使用者名稱`,Trello 可能會把它當成「提及」並通知對方。** 如果不希望打擾對方,請不要指定成員。
- 成員以 Trello 使用者名稱儲存。若留言中的使用者名稱不在該看板的成員清單內,會直接顯示 `@使用者名稱`。
- Trello 只允許修改或刪除**自己寫的**留言。別人建立的區間會以半透明色條與 🔒 顯示,無法在這裡調整、改名、指定成員或刪除。
- 每個看板最多讀取最近 10,000 則留言;留言非常多的看板,較舊的區間可能不會出現。
- 卡片視窗的「留言」區塊仍會列出這些留言,若手動修改留言內容,區間會跟著改變。

## 事前準備:取得 API Key 與 Token

1. 到 <https://trello.com/power-ups/admin> 建立一個 Power-Up,複製 **API 金鑰**(Key)。**密碼(Secret)用不到,請勿外流。**
2. 把下面網址中的 `你的API金鑰` 換成你的 Key,用瀏覽器開啟並按「允許」,頁面顯示的那串文字就是 **Token**:

   ```
   https://trello.com/1/authorize?expiration=never&scope=read,write&response_type=token&name=TrelloGantt&key=你的API金鑰
   ```

   - `scope=read,write`:修改日期、成員與留言需要寫入權限。只想看圖的話可改成 `scope=read`。
   - `expiration=never`:Token 不會過期。想保守一點可改成 `30days`。

## 使用方式

### 方式一:直接在本機使用
下載 `trello-gantt.html`,用瀏覽器開啟即可,不需要設定 Power-Up 或任何網址。

### 方式二:掛成 Trello Power-Up
1. 把 `index.html` 與 `trello-gantt.html` 放到任何公開的 HTTPS 空間,例如 GitHub Pages、Netlify、Cloudflare Pages。
2. 到 Power-Up 管理頁面設定:
   - **Iframe connector URL**:`https://你的網域/路徑/index.html`
   - **Allowed Origins**:`https://你的網域`
3. 在看板的 **Power-Ups → Custom** 加入這個 Power-Up,看板右上角會出現「甘特圖」按鈕。

> OAuth 2.0 的「回呼 URL」不需要填,本專案沒有使用 OAuth 流程。

### 操作流程
1. 在「連線 Trello」貼上 API Key 與 Token,按「載入看板」。
2. 勾選要處理的看板,按「產生甘特圖」。
3. 用工具列調整成員篩選、時間刻度與是否顯示無日期、無成員卡片。
4. 直接拖曳色條改日期,或點卡片開啟視窗管理日期、成員與留言。
5. 按「匯出 Excel」或「匯出 PDF」。

## 注意事項

### 安全
- API Key 與 Token 只存在使用者瀏覽器的 localStorage,不會傳送到 Trello 以外的地方。
- **Token 等同你的 Trello 權限。** 不要寫進程式碼,也不要上傳到公開的 repository。外流時,請到 <https://trello.com/my/account> 的授權應用程式撤銷。
- 在共用電腦上使用後,請清除瀏覽器資料。

### 拖曳編輯
- 拖曳放開後會**立即寫入 Trello**,沒有確認步驟。拖錯時,再拖回原位即可。
- 儲存失敗時(例如權限不足),畫面會自動還原並顯示錯誤訊息。
- 拖曳一律同時寫入開始與結束日期。原本只有結束日期的卡片,拖曳後會多出開始日期。
- 在只有單一日期的卡片空白處拖曳,會補齊並重設該卡片的原生開始與結束日期。
- 拖曳以「天」為單位對齊,在月、年刻度下也一樣。
- 移動卡片只能在同一個看板內進行,且需要開啟該看板的「顯示列表」。
- 開啟「顯示列表」時,列表內的卡片依 Trello 的順序排列(才能調整順序);關閉時則依開始日期排列。
- 列表會全部顯示,包含目前沒有卡片(或被篩選掉)的列表,方便把卡片移進去。

### 日期與時間
- 所有日期以台灣時間(UTC+8)顯示與計算。
- 修改日期時會保留卡片原本的時間。原本沒有日期的欄位,預設開始 09:00、結束 18:00。
- 日期視窗中兩個日期都清空,卡片會變成「無日期」,不會被刪除。

### 成員與留言
- 新增成員時只能選該看板的成員。
- 只能編輯自己寫的留言,別人的留言只能查看(Trello 的限制)。
- 目前不支援刪除留言。

### 匯出
- PDF 是把圖表轉成圖片再輸出,中文不會亂碼,但 PDF 內的文字無法選取或搜尋。頁尾的頁碼與日期範圍只使用英文與數字。
- 區間在 62 天內以「日」為單位,較長時自動改以「月」為單位。區間過長(橫向超過 40 頁)時會提示縮短區間或改用 A3。
- 目前的成員篩選與「顯示列表」設定會套用到 PDF;列表的收合狀態則一律展開,空的列表不會列出。
- 匯出 PDF 一律使用淺色配色,方便列印。圖表是在畫面外另外繪製,畫面上的深色或淺色主題不會被切換。
- Excel 與 PDF 的函式庫從 cdnjs 載入,使用時需要能連上網路。

### 限制
- 已封存的卡片不會讀取。
- 沒有成員時,卡片欄位只顯示卡片名稱。
- 一次選很多看板時,讀取會比較久。Trello API 有請求次數限制(約每個 Token 每 10 秒 100 次),程式已在看板之間加入短暫間隔。
- 目前不支援刪除留言,也不支援修改卡片名稱、描述、列表或看板。
- 卡片描述以純文字顯示,Markdown 語法不會轉換;很長的描述在視窗內可捲動。
- 收合列表的狀態不會保存,重新產生甘特圖後會全部展開。

## 疑難排解

| 狀況 | 可能原因與處理 |
| --- | --- |
| 載入看板失敗 | API Key 或 Token 貼錯,頁面會顯示 Trello 回傳的錯誤訊息 |
| 拖曳、改日期、改成員或留言時顯示「權限不足」 | Token 只有讀取權限,請用 `scope=read,write` 重新產生 |
| 在 Power-Up 裡無法讀取資料(CORS 錯誤) | 確認 **Allowed Origins** 已加入網站網域 |
| 看板上沒有「甘特圖」按鈕 | 確認 Iframe connector URL 正確,且已在看板加入此 Power-Up |
| 找不到某張卡片 | 檢查「顯示成員」是否被篩選,以及「顯示無日期卡片」「顯示無成員卡片」是否已勾選 |
| GitHub Pages 打開是 404 | 剛部署需要 1 到 2 分鐘,稍後再重新整理 |
| 更新檔案後畫面沒變 | 瀏覽器快取,按 Ctrl+Shift+R 強制重新整理 |
